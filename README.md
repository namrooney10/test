# Dự án Python đầu tay của Nam
Đây là kho lưu trữ các bài tập Python cơ bản của mình.

## Các bài tập bao gồm:
* `solocphat.py`: Bài toán kiểm tra số lộc phát.
* `soxenke.py`: Thuật toán xử lý chuỗi số xen kẽ.
* `main.py`: File chạy chính của chương trình.

## Cách chạy code trên máy tính:
Chạy lệnh: `python main.py`
